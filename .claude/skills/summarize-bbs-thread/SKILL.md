# Summarize BBS Thread

用於「讀一串文章後整理摘要」，不是直接回一句短回文。

## Use This Skill When

- 使用者要你整理長串
- 使用者要你先做摘要草稿，再決定要不要發出去
- 文章有多篇 `Re:`、短接話、重複觀點，需要去重

## Default Workflow

1. 先鎖定目前文章或指定篇號。
2. 若只知道主題關鍵字，不知道篇號：
   - 優先在看板列表使用 `~` 進入串接模式。
   - 正確流程是：
     1. 先送 `~`
     2. 輸入關鍵字後按 Enter
     3. 視需要填作者 / ID 字首，再按 Enter
     4. 視需要選 `m` 標記文章 `y/n`
     5. 視需要填 GY 下限
     6. 看到 `【主題串列】` 才算真的進搜尋結果
   - 例如：只靠主題找串時，可輸入 `NS2` 或 `你各位再不升級`。
   - 這招比 `/關鍵字` 更適合找長串或標題變體。
3. 若只知道作者 / ID 或只想用 GY 篩選：
   - 也一樣從 `~` 串接模式進去。
   - 關鍵字可留空，直接 Enter。
   - 作者 / ID 篩選可只填字首；若第一個字填 `*`，可做模糊搜尋。
   - GY 下限也可單獨使用，不一定要搭配關鍵字。
4. 若列表底部殘留舊搜尋字串，先重整狀態再找：
   - 優先回到乾淨的看板列表後再輸入 `~`
   - 若畫面已被舊搜尋污染，先用 `bbs_reset_screen`，必要時重連
5. 優先使用 `bbs_collect_thread` 收集 seed 文與相關主題文章。
6. 若要直接出草稿，使用 `bbs_summarize_thread`。
7. 先把摘要草稿給使用者看。
8. 只有在使用者明確要求時，才交給 `post-to-bbs` 流程發出去。

## Output Modes

### `neutral`
- 用於中性整理
- 適合「幫大家快速看懂這串在講什麼」
- 不要寫得像在吵架站隊

### `bbs_post`
- 用於貼回板上的摘要草稿
- 仍保持中性
- 句子要短，避免像報告

## Summary Rules

- 主文權重最高，不要被大量短 `Re:` 稀釋。
- 引言不是正文，不要把 `> ...` 當成摘要主體。
- 同一句意思重複出現時，只保留 `1-2` 篇代表回文。
- 若後續回文多半只是接話、補刀、換句話說，摘要要合併，不逐篇列出。
- 若出現新分支，才開新一點。
- 沒有明確共識時，要直接寫「目前沒有明確共識」。

## Stop Rules

- 連續多篇都只是重複原本的點
- 明顯開始偏題
- 已經收集到足夠代表性的回文

## Posting Guard

- 摘要完成後，預設只顯示草稿，不直接發文。
- 若要發回 BBS，先檢查：
  - 是否仍然中性
  - 是否有把重複觀點壓縮
  - 是否沒有把引言內容誤寫成新觀點
  - 是否沒有多帶不存在的結論
- 若使用 `~` 找串，不要把「底部出現串接模式」當成成功。
  - 一定要確認最後真的進到 `【主題串列】`。
