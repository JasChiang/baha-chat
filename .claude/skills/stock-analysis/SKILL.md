# 台股技術分析（中性訊號版）

**首要原則**：本 skill 只提供「技術面訊號判讀」，**不構成投資建議**，禁止寫「買進 / 賣出 / 目標價」這種明牌語句。永遠假設使用者要的是「資訊整理」，不是「下單依據」。

## 流程

### 1. 解析 symbol
- 純 6 位數或 4 位數 → 股票代號
- 含「@PipboyAI」「@iamchatai」這類 BBS 標記要先剝掉
- 上市（4 位數開頭多為 1-9）→ `stock_history` 走 TWSE STOCK_DAY API
- 上櫃（4 位數開頭 3、8 等，例 8069、8299、3008）→ `stock_history` 自動 fallback 到 FinMind（免費、無 token）
- ETF（00 / 009 開頭，例 0050、009816）大多在 TWSE，照上市走
- **大盤指數**：「加權」「TAIEX」「t00」「大盤」自動 normalize 到 `tse_t00.tw`；「櫃買」「TPEX」「o00」自動 normalize 到 `otc_o00.tw`。`stock_quote` 直接吃這些 alias。

### 2. 抓資料（順序固定）
```
1. stock_quote(symbols=[code])          # 即時報價、五檔、漲跌停
2. stock_history(symbol=code, days=120) # 日 K 120 天（足以算所有指標）
3. stock_indicators(symbol=code,        # 算指標
     indicators=["ma5","ma10","ma20","ma60","kd","macd","rsi","boll"],
     days=120)
```
若 user 明確只問短線：days=60 也夠。
若 user 問月線/季線：days=240。

### 3. 套訊號詞典（內部判讀）

**趨勢類**
- 收盤 > MA5 > MA10 > MA20 > MA60 → 「均線多頭排列」
- 反之 → 「均線空頭排列」
- MA20 上彎且收盤站上 → 「中期結構轉強」
- 收盤跌破 MA60 且 MA60 下彎 → 「中期偏空」

**動能類**
- KD: K > D 且 K 在 20-50 之間翻揚 → 「KD 低檔金叉」
- KD: K < D 且 K 在 50-80 之間下彎 → 「KD 高檔死叉」
- K > 80 → 「KD 過熱」（不等於要賣，但動能末段）
- K < 20 → 「KD 過冷」（不等於要買，反彈訊號之一）
- MACD hist 由負轉正 → 「MACD 翻多」
- MACD hist 由正轉負 → 「MACD 翻空」
- MACD 連續 3 日 hist 擴大 → 「動能加速」

**波動類**
- 收盤觸碰布林上軌 → 「短線過熱」
- 收盤觸碰布林下軌 → 「短線過跌」
- 布林帶寬縮窄 → 「波動收斂，等變盤」

**RSI**
- RSI(14) > 70 → 「短線超買」
- RSI(14) < 30 → 「短線超賣」
- RSI 50 中軸是多空分水嶺

### 4. 三套 preset（依使用情境）

#### 4a. `conservative` — 保守派
看：MA20、MA60、KD（日線）、量
規則：
- 多頭：收盤 > MA20 + KD 低檔金叉 + 量增 → 「結構偏多」
- 觀望：收盤糾結 MA20 ± 2% + KD 在 40-60 → 「整理中」
- 偏空：收盤 < MA20 且 MA20 下彎 + 量縮 → 「結構偏空」

#### 4b. `aggressive` — 積極派
看：MA5、MA10、MACD、布林
規則：
- 進場訊號：收盤 > MA5 > MA10 + MACD 翻多 + 觸布林上軌 → 「短線動能強」
- 退出訊號：MACD 翻空 + 跌破 MA5 → 「動能止息」
- 反彈訊號：收盤觸布林下軌 + RSI < 30 → 「超跌反彈候選」

#### 4c. `momentum` — 動能派
看：MACD 連續 hist 走勢、量價配合
規則：
- 連續 3 日 hist 擴大 + 量增 → 「動能加速中」
- 連續 2 日 hist 縮小 → 「動能轉弱」
- 量大價跌 → 「警示」（爆量 ≠ 反轉，但要留意）

預設 preset：`conservative`。除非 user 明確說「短線 / 積極 / 動能」才切其他。

### 5. 輸出格式

#### 5a. 給人讀（聊天 / 對話模式）

格式：
```
【XXXX 股名】
資料截止：YYYY-MM-DD（盤中近即時 / 昨日收盤）

短摘要：
[一句話總結，不要明牌]

技術面：
- 趨勢：[均線排列描述]
- 動能：[KD / MACD 狀態]
- 波動：[布林 / 量能]

訊號偏向：[偏多 / 偏空 / 觀望]（preset：conservative / aggressive / momentum）

注意：
- 本內容為技術面整理，不構成投資建議
- 漲停鎖死 / 跌停鎖死 等特殊狀況另論
```

#### 5b. 給 BBS（套用 post-to-bbs 的 5 鐵律 + 人味）

格式（短版，8-10 行）：
```
@提問者 順手幫看
XXXX 股名（上市/上櫃）
現在 XX.XX，比昨收漲跌 X.XX%
[一句趨勢觀察]
[一句動能觀察]
[一句注意點]
時間 HH:MM 抓的

訊號偏向 OO，不過真的要說買賣那我不敢
```

**BBS 模式硬規則**：
- **不能寫**：「買進」「賣出」「進場」「出場」「明天會漲 / 跌」「目標價 XXX」「停損 XXX」這種直接指令
- **可以寫**：「訊號偏多 / 偏空 / 觀望」「結構偏弱」「短線動能強」「上面 XX 那關過不過」「下面 XX 撐得住嗎」
- **必須有 disclaimer**：可以含蓄（例：「真的要說買賣那我不敢」「不一定對」「我這邊頂多看訊號」）
- **必須有時間戳**：「XX:XX 抓的」「截至昨日收盤」
- **長度限制**：盡量壓 ≤ 12 行（含簽名），不要寫研究報告

### 6. 特殊狀況

- **漲停鎖死**：賣五檔全空、`z` 等於漲停價。寫法：「鎖死漲停 / 跌停，技術面失效，等明天再看」
- **盤前 / 盤後 / 休市**：`stock_quote` 的 `z` 是「-」是正常的，這時用前一日收盤 + 歷史指標來談「截至昨日」
- **資料異常**（連續多日無交易、新股、KD 失真）：直接說「資料不足或異常，技術面判讀請保守」
- **OTC 上櫃股**：`stock_history` 現在會自動 fallback FinMind 拿日 K，正常跑指標。回文時可選擇是否提來源（一般不用提，太工程）。
- **大盤位置確認**：分析個股訊號前，如果是「方向性問題」（漲到哪、跌到哪、要不要進），可選擇先 `stock_quote(["加權"])` 跟 `stock_quote(["櫃買"])` 看大盤方向。多頭市場個股訊號的可信度比較高。

### 7. 跟 post-to-bbs 的銜接

如果這次任務是「BBS 上有人 @ 問股票」：
1. 走完 1-4 步（拿資料、判訊號）
2. 切到 BBS 模式（5b）寫回文，**強制套 post-to-bbs 的 5 鐵律**：
   - 換行 = 完整子句
   - 不省連接詞
   - 句中無半形空格切句
   - 有語助詞收尾
   - 長句可一行寫到底
3. 用 `bbs_reply_to` 一條龍貼出去

### 8. 法律 / 道德守則

- 台灣發布投資分析需要證券分析師執照。本 skill 用於「個人資訊整理」「BBS 閒聊」性質，不對外提供付費或具體建議。
- 永遠標明 AI 身份（BBS 上靠簽名「本文由 AI 發送」）
- 永遠標時間戳
- 從不主動推銷單一股票
- 從不提供「明牌」「飆股」「報明牌」「神準」這種用詞

## 常用組合範例

**範例 1：使用者問「2330 現在訊號如何」**
```
1. stock_quote(["2330"]) → 拿即時報價
2. stock_history("2330", 120)
3. stock_indicators("2330", ["ma5","ma20","ma60","kd","macd","rsi","boll"])
4. 套 conservative preset → 寫 5a 格式
```

**範例 2：BBS 上 @ 問「8299 訊號」**
```
1. stock_quote(["8299"]) → 拿即時報價
2. 注意：8299 是上櫃，stock_history 會 error
3. 直接用快照 + 五檔做判讀（沒有歷史指標）
4. 寫 5b 格式 + 註明「歷史 K 線暫無法接 TPEX」
```

**範例 3：使用者問「給我看一下 0050 中長期格局」**
```
1. stock_quote(["0050"])
2. stock_history("0050", 240)
3. stock_indicators("0050", ["ma20","ma60","ma120","ma240","macd","rsi"])
4. 重點看 MA60 / MA120 / MA240 排列 + 月線位置
5. 套 conservative preset → 5a 格式
```
